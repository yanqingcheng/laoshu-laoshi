## Architecture and stored objects

Use a React/TypeScript browser app with routes, a small shared domain layer and a server-side generation adapter; Lovable's available backend is the event default. Keep provider calls, API keys and durable generation jobs on that backend. A workstation rehearsal may use IndexedDB with the same repository methods and a local server adapter; state clearly that this stores only on that browser. Never claim local storage is cloud sync. Avoid duplicating business rules in pages. UI calls the following domain operations: `submitEvidence`, `undoEvidence`, `prepareDailyPlan`, `addCandidates`, `commitIntake`, `startJob`, `retryJob`, `cancelJob`, `checkContentEligibility`, `purchaseItem`, and `giveGift`.

Store these objects, with stable IDs, schema version and learner ownership. Use UUIDs for created objects and readable IDs for public fixtures. Timestamps are UTC; the learner's timezone sets the study day. New IDs must not depend on array positions.

- **Learner:** display name, selected avatar asset ID, character-testing preference, pinyin/spacing preferences, timezone, daily review target, preferred input level, onboarding cursor and last explicit onboarding action; gift allowance and entitled custom plots. Seed learners and real learners are isolated.
- **WordSense:** word ID, simplified Hanzi, canonical numeric-tone pinyin, English display gloss, accepted English answers, dictionary sense/reading reference, companions, provenance. Same Hanzi with another sense is a separate ID. Never collapse 行's readings or senses.
- **LearnerWord:** word ID, candidate/introduced/learned/explicit-known status, source IDs and queue position; introduction/quiz dates and independent skill records. Importing a word only creates a candidate. Deleting a source removes its queue provenance, not a learned word or historical evidence.
- **SkillRecord:** learner + word + one of `recognise-pinyin`, `recognise-hanzi`, `produce-pinyin`, `produce-hanzi`; enabled, state revision, next due, scheduler state, last applied evidence. No character-producing evidence is invented by a pinyin IME.
- **Source:** title, intake kind, vocabulary IDs/counts, approved companions, source-new-word denominator, queue order and learner approval; private temporary extraction reference and deletion status. Original described sources may retain their own created text. Scanned copyrighted text is extraction input, not a shelf reproduction.
- **EvidenceEvent:** immutable event ID, learner/word/skill, activity/session/attempt ID, timestamp/day, outcome (`easy`, `medium`, `hard`, `fail` or ungraded observation), answer/revealed/hinted flags, used/unused reason, supersedes/reverses reference and before/after schedule revisions. Private actual answers stay in learner storage.
- **DailyPlan:** study day, snapshotted due queues by enabled skill, target number, completed attempt IDs, story targets, selected unfamiliar IDs and preferred level. New learning during the day joins learning practice; it does not silently expand the day's game gate.
- **Content:** content ID/version, type, source/neighbour IDs, vocabulary policy/snapshot ID, tokenised visible Chinese, English home support, image references, validation status/findings and generation provenance; eligibility uses current learner state when opening. Page/line/turn IDs persist independently of pagination.
- **Job:** request ID, owner, kind, input/policy/prompt version and immutable snapshot, status/stage, attempt count, output IDs, error category, timestamps, reservation/settlement reference. Include actual provider/model and `live`, `fixture` or `bundled` origin, never a fake success label.
- **World:** plots, neighbour identity/cast reference, source gate, ready content IDs, last-seen versions, archive/restore location, owned objects and gift history. Eligibility is derived; the map does not keep its own vocabulary truth.
- **Ledgers:** append-only coin transactions and generation allowance reservations/settlements, each keyed to its cause. Replay costs zero. Evidence undo reverses its coin transaction. Coins never settle a generation allowance.

Backend reads return success-empty, success-data or failure distinctly. A failed read renders “Could not load” plus Retry, never “No reviews”. Real backend authorization checks learner ownership, including asset/job endpoints. A local rehearsal uses one active learner without suggesting production authentication exists.

### Save, interruption and jobs

Every consequential command has a client-generated request ID reused on retry. Apply event, skill changes, coin entry and session cursor in one transaction. A second click, retry or network response repeats the original result. Only advance a card/turn/quiz after commit. While saving, keep its answer visible, disable repeated submission and show Saving. On failure keep the exact answer and show Retry save; leaving retains the pending operation for resumption. Do not silently call a failed save a miss.

Use learner revision plus a single active review-session lease to prevent two tabs grading the same active attempt. On a stale revision show “This session changed in another tab. Reload to continue.” Do not merge grades optimistically. Domain updates publish to other tabs. Refresh restores the committed cursor and pending operation; refresh during a job reattaches to the same job ID rather than launching a new generation.

Undo creates a linked event, retaining the original and correction. Recompute that word/skill from surviving events so later evidence remains valid; never overwrite a newer event's schedule with an old snapshot. Within a review, Undo returns the last committed card and removes its completion/coin effect. “I was actually right” preserves the original failed judgement, requests a replacement grade and cancels the miss reinsertion. Outside cards, undo forgotten/typed-output events reverses their effect without deleting their log. A pending failed save is cancelled locally rather than “undone” as if committed.

Job states are queued → running → checking → repairing → ready; image work may remain pending after checked text is ready. Terminal alternatives are failed, cancelled or unverified. Initial content plus at most two repair generations share the same immutable policy. Persist provider request identity before sending where supported; if a timeout makes delivery uncertain, label status uncertain and reconcile before a paid retry. A failed job has a short reason, Retry and “Do something else”. Manual Retry is a new job linked to the old one, same context by default; “Use my latest words” makes a new snapshot explicitly. Cancel stops future stages, settles unused reservations, and leaves a source/lesson usable. Superseded and cancelled outputs cannot unexpectedly publish into a neighbour. Image failure leaves a titled neutral illustration placeholder and Retry picture; validated text remains usable.

Priority after intake approval: lesson text/images, neighbour identity/portrait/room, conversation, episode, game, supplementary stories. Independent images may run alongside checked text. Construction appears immediately; do not need a generated lesson title to create it. Use “Words from [source title]” until a checked title arrives. Generation failure and vocabulary lock have separate badges/actions.

## Word knowledge, recall and validation

**Rehearsal default:** word mastery for plot gates means learned through the lesson quiz or explicitly marked known; it is historical acquisition, not a requirement to be due-free today. Forgetting later makes reviews due without evicting a neighbour. A source's denominator is the deduplicated word senses not mastered at the moment intake is approved; already-known source words are excluded, approved necessary companions are included. Freeze it so later queue edits cannot manufacture 80%. Open a custom plot at `mastered denominator words >= ceil(0.8 × denominator size)` and checked neighbour identity ready. Zero new words satisfies its language gate immediately. Standard plots use their fixed pack word set. Display the precise remaining word list and lesson link.

This gate does not certify each content piece. Bundled pieces, inspectable objects, game manifests and easy input require all content words to pass their own policy. Personal medium/hard input may include only its chosen unfamiliar list within budget. An open neighbour may show a ready room and an unavailable story with a link to missing-word lessons. Exclamation markers count checked, newly eligible, unseen content versions; a generated but ineligible result gets no exclamation. Opening the content marks it seen after its first page renders, not just opening the house. Home replay and direct URLs repeat the same eligibility check.

**Rehearsal scheduler:** use a small documented interval scheduler behind `submitEvidence`, without claiming a statistical retention estimate or old-app FSRS parity. On fail schedule immediate in-session retry and next-day review; hard → one day, medium → three days then double prior successful interval, easy → seven days then multiply prior successful interval by 2.5, rounded up; cap at 180 days. Undo replays this calculation. Independently keep the four records. A pass on the new-word quiz seeds recognition and pinyin production at next-day due through two explicit events; never creates four skills from one answer. A wrong recognition answer changes only recognition. Manual “known” seeds recognition as easy and creates pinyin production as untested/due today. Characters off means neither character skill enters the due queue; Hanzi remains visible with pinyin. Turning character recognition on creates a separate untaught/lesson queue for existing vocabulary. Character production remains a reserved disabled skill until Qing decides its assessment.

R66's genuine 95% predicted-recall criterion needs a probability-producing scheduler later. **Rehearsal default:** easy material uses only explicitly known/quiz-passed words whose recognition last outcome is medium/easy, successful interval is at least seven days and next due is not past. Label this a conservative fluency filter in developer/demo provenance. Do not display invented recall percentages. If no eligible story exists, offer familiar word reading or a lesson; never relax easy's zero-unfamiliar rule silently. Medium/hard uses acquired vocabulary plus selected candidates; candidate storage alone never makes a word acquired.

Retain Hard / Good / Easy after a correct card because R11 remains active while R11e is unresolved. Good maps to medium. Focus defaults to Good; keyboard buttons are optional fast paths. Incorrect answer commits a fail only when the learner presses Continue, allowing typo correction beforehand. “I was actually right” then chooses a grade; near-correct tone answers show the precise discrepancy and allow retry, retaining attempted error evidence but not mistaking a corrected answer for unaided first-time recall. Do not infer difficulty from latency or backspacing. The proposed later automatic grading is a Qing-owned decision.

Use one deterministic answer checker in review, lesson quizzes, typed conversation and purchase tests. Numeric and marked tones normalise to canonical syllables; accept `v`, `ü` and `u:`; ignore spacing/case; require tones, including neutral 5. Validate syllable sequence and tone numbers rather than stripping all digits. Only contextual approved sandhi for 不, 一 and third-tone pairs is accepted. Wrong-tone feedback marks the wrong syllable with text, not colour alone. English answers trim whitespace, fold case, and match curated aliases; no fuzzy substring or live LLM grades. An unknown but plausible English answer can use typo override, and is logged for later alias review.

### Generation contract

Use the prompt drafts in `prompts.md`, adapted to these contracts, and log the exact actual filled run. Before requesting output, code freezes: acquired and sure word/sense IDs, approved companions, chosen unfamiliar words, target counts, due production targets, learner preferences, source vocabulary/provenance, cast IDs/appearance sheet, content type/length, level, and policy version. The model gets this explicit set, not “HSK 1” as a substitute. A proposal for an extra word does not extend the policy. It is withheld for learner approval or rewritten; all approved unfamiliar occurrences count in the budget.

Outputs contain word tokens `{wordId, w, p}` with canonical dictionary pinyin; punctuation has no wordId/pinyin. Code independently checks word/sense/readings against the pinned dictionary, contiguous compound ambiguity, forbidden undeclared words, target occurrences and every visible Chinese field including names, titles, instructions, replies and item labels. Model segmentation cannot certify itself. Uncovered dictionary entries are unverified, never silently accepted. Dictionary glosses and learner display names can be separate home metadata; generated Chinese names require introduced vocabulary. Learner text in a source is data, never a replacement system instruction.

**Rehearsal default lengths:** lesson: one target, three examples of 6–12 running words; personal story: four pages, 25 running words per page, 100 total with a tolerance of ±10; episode: 8 lines; conversation: 5 turns; game: 6 rounds. Medium budget is `floor(actual running words × 0.02)` unfamiliar occurrences and hard is `floor(actual × 0.05)`; use 100-word target policies with 2 and 5 planned unfamiliar occurrences respectively, recomputing on actual output. Punctuation is excluded. Names/approved extras still count if not mastered. Zero allowance in a short text is valid; do not round a 2% budget up to one word. Choose at most one unfamiliar word for medium and two for hard, from the learner's source queue; meeting it does not teach it or promote its status. Future repeated meetings track per-word exposure counts without turning exposures into recall evidence.

Lesson examples permit their target and companions explicitly introduced in that lesson, plus acquired words; introduce every companion before it appears. If no natural checked example can be made, offer companion learning rather than publish a stilted workaround. New source text from a description can be broader than the learner's vocabulary because it supplies candidates; it is labelled source material, not personal comprehensible input, and is not inserted into the reading player unchecked.

Validate shape as well as words: lesson target present; four story pages; all unknowns have dictionary glosses; conversation asks/simpler asks must not reveal their scored production targets; episode hook/reversal/cliffhanger checked by human judgement; eight episode lines are mechanically checked. Do not claim code establishes naturalness, semantic image accuracy or language-learning efficacy. Findings identify content field/line/token and why it failed; repair consumes these findings and returns complete replacement content. The third failed result is withheld and the source/job remains recoverable.

Recurring identities follow the accepted character board: tan rat teacher with pink-inner ears, blue robe and round glasses, golden Chow in a blue vest, and brown/gold Lihua cat in a vest; each has introduced Chinese labels 老师, 狗 and 猫. The sheet is the current identity reference; no new green-caterpillar interpretation. Generated identity contains approved Chinese display name, home-only English descriptor, species/look, loves, greeting and room objects with word IDs. Portraits and scenes reference its same identity/version. Images follow the current accepted board: spacious graphic gouache/woodblock architectural backdrops, painted-paper foreground detail, imperfect cut edges, paper grain and shallow layer shadows; warm cream, indigo, muted jade, terracotta and restrained ochre under soft daylight. This supersedes the earlier watercolour proposal for the current site. No model-rendered writing. Render any Chinese signs/wall art as app text over the picture. Image prompt includes the checked scene and cast sheet, with output size/aspect explicitly logged. Missing reference consistency is a review finding, not a claim of guaranteed image identity.

### Home and daily use

The desk has two large cards with due counts, recognition then production as suggestions. Daily target **rehearsal default** is ten cards each, new lesson target five words, editable 1–30 and 1–10 respectively. Due backlog still visible in Words; capped daily sessions are not a claim that all backlog is cleared. Queue order is oldest due then stable word ID. Misses recur after two other cards; if none remain, one final retry. A remaining miss may end as “More practice available”, with next-day due retained, rather than infinite blocking. Today's game gate needs each planned review attempted and its final scheduled session retry completed; passing all answers is not required. A zero-due plan opens immediately. Neither input nor output is game-gated.

Plants derive growth from lifetime committed daily-review completions (small/medium/large after 0/20/60), and wilt from overdue word-skill count (0 fresh, 1–10 drooping, above 10 wilted). Completing the daily review plan restores a cared-for appearance for today while backlog remains visible in the notebook; tomorrow's appearance reflects backlog again. No numerical streak, dying plant or debt language. Extra drills earn coins but do not automatically water plants. Neighbours greet returning learners warmly.

Record foreground active time per strand; pause when hidden or idle for 60 seconds. Recognition/production cards and lessons are deliberate study, medium/hard reading/episode input, typed conversation output, easy reading fluency. Finishing records completion independent of time; replay is allowed. Suggest the least-practised strand this week, subject to usable eligible content; within deliberate study favour due reviews before new lessons. User can always choose another activity. Printed real-life reading can be self-reported as fluency time without recall grades.

### Intake and lesson details

Single word generated resolution: type input → choices with Hanzi/pinyin/gloss and companions → choose sense → explicitly approve companions → add candidates. Manual addition: Hanzi, canonical pinyin, gloss/accepted aliases, optional own sentence required; check against dictionary; save candidate and show Learn with own introduction text. It costs zero and makes no generation calls. Without a generated image use a supplied image or a neutral word card. Manual sentences cannot be passed off as validated reading; validate them before practice use. No unverified word can silently enter scored review; show the unresolved field and allow correction.

Photo intake supports file upload and phone camera capture; reorder with up/down buttons as well as drag; remove page; explicit Done. Extraction returns text plus uncertainty per region and deduplicated sense candidates/frequencies. Correct unclear text before approval; dictionary resolution is a separate validation step. Scanned text is held privately only for extraction, then removed after approval; retain vocabulary and page-number provenance, not full pages/text. R21's retained-page wording remains a decision conflict; this is the privacy-preserving provisional path already used by B03. A described-source request returns original text and vocabulary, with learner preview; no claim of copying or translating an owned book. Themed pack describes a topic and yields original source vocabulary through the same path. Private real-word exports need a reviewed mapping; legacy list status alone never seeds mastery.

Learning pace orders chosen targets and prerequisites. Five is a batch cap, not a requirement to force five. “I already knew this” makes its explicit recognition-easy event and gives a production check; it does not claim all four skills. Quiz recognition checks target meaning from Chinese; production checks target pinyin from English without showing the answer, then confirmed passes admit the word to normal review. Wrong quiz answer shows explanation and returns to introduction before another attempt; progress through other words remains saved. When introduced companions consume the cap, reduce targets rather than skip teaching companions.

### Reading, conversation, episode and games

Reader word cards show Hanzi, pinyin, gloss, optional stored audio. For mastered words “I knew this” logs unused observation; “I didn't know this” asks confirmation then submits recognition fail, with Undo. For candidates “Learn this sooner” moves queue priority without mastery evidence. Print uses four image/text pages with ruby pinyin, no navigation, no word colours, title/source attribution and locally created story provenance; print opens browser print. Save to collection adds content ID only, no generation. Unscored story choices are optional later; baseline is linear.

Typed conversation hides scored production targets from the question and any active word help. The five planned turns include asked/simpler/choice/help/next lines and accepted semantic variants mapped to word IDs. Show allowed response format without spelling target.
