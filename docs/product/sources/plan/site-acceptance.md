# Check that the text/image site works

Use [site-spec.md](site-spec.md) as the implementation target and [requirements.md](requirements.md) for product authority. This is a compact review checklist for a fresh builder and demo rehearsal, not a claim of tested coverage. Mark a case passed only after observing it on the built site. Save failures and dictionary checks deserve deterministic checks; judge language naturalness, picture consistency and usability by reading/using the result. Run the normal journey once, then the relevant failure/interruption cases; no repeated whole-product audit is required.

A successful hackathon slice is a finished journey with an honest origin label and a usable next action. Text/still substitutes are accepted for this selected scope; they do not complete the deferred speech/video requirements. Each build prompt should select the cases for what it actually implements. Unbuilt future routes are backlog, not passes.

## Three normal journeys

**Tom, fresh source.** Reset synthetic Tom; home shows room/list, due recognition and production, recoverable plants and today's game waiting for reviews. Do one recognition card and one pinyin-production card; reload and see their committed progress. Add the original `source-demo-garden` fixture, distinguish five candidate words from acquired words, and see the construction plot immediately. Approve companions/order, learn four words and pass their two text quiz checks. The source gate reaches 4/5, the caterpillar house opens only when checked identity is ready, and its 蝴蝶-dependent piece remains withheld. Open checked reading, typed conversation, illustrated episode and game. Finish review plan to open today's game; replay saved content from home. Nothing needs a microphone, playable audio or video.

**Tom, bounded short demonstration.** Reset to the visibly labelled resumed-source checkpoint: source's frozen denominator five, three historically acquired through post-intake quiz passes (not mastery of all skills), one remaining cake lesson needed for 80%. Teach cake; gate becomes 4/5 without modifying the denominator. Open the same house and demonstrate that butterfly content still waits. Show fixture provenance; do not call the checkpoint live acquisition. R18, R24–R29, R80–R89, R124–R130.

**Brand-new person.** Fresh profile → name → one of ten avatars (or capped image batch) → No → still-image arrival → lesson 0 introduction/quiz → unscored matching game → skippable room tour. Word records start empty; no word becomes learned just because it was shown in an arrival bubble. Shelf offers pack 1, home/park/gym/grammar have useful introduction or practice paths, shop explains its vocabulary lesson and the gift custom plot is visible. There is no empty first day. R17b, R17i, R76i–R76j, R131–R134, R138–R139.

**Existing Chinese.** Fresh profile → name/avatar → Yes → individual swipes/buttons with persistent next-ten preview → optional Stop/Keep going → arrival without lesson 0 → partly open town. Keep a later word and decline an earlier one: shelf still offers that missing earlier word, and bundled content requiring it stays unavailable. Reopen midway through swipes: saved choices/cursor persist; unvisited previews remain candidates. Kept words seed recognition-easy and pinyin production-due only, not four skills. R17a–R17j, R2, R76h.

## Honesty and review boundary

Inspect the public repository: only fresh authorised code and public original synthetic data/assets; no real learner export, source photographs/scanned text, secret keys or private filled prompts. Every actual provider/build generation run is logged exactly, with actual model/settings/input references/output paths and kept/cut outcome; retries are separate entries. Draft prompts and handwritten fixtures are not labelled tested model output. Local-only persistence and entitlements stub are identified honestly. CLAUDE.md, R18, R21/R33a conflict, R76–R79.

Read one checked lesson, story, conversation and episode for natural Mandarin, target support and neighbour/picture consistency; mechanical vocabulary pass alone does not settle those qualities. A reviewer should identify concrete broken behaviour or unclear build choices, not start another product-design round.

Deferred acceptance remains future work for actual audio/listening/voice/video, handwritten character production, full curriculum and statistically calibrated recall, extensive town jobs/arcade/archive rules and production money/account flows. Text/image passes above must not be reported as proving those capabilities. Qing-owned grading, town gloss, mastery metric and pricing choices remain reversible assumptions, with the implemented defaults recorded in the spec.
