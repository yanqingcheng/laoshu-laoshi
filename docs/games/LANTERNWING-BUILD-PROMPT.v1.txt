RULES
Ten course number requests, one through ten, in supplied order: 3,1,5,2,7,4,9,6,10,8.
The target is only the supplied Mandarin number (with trusted marked ruby), never
an Arabic target, countdown, target-sized rack or target-colour cue. Current cargo
may show an Arabic number and actual orbiting captured lights. A wordless demo and
first guided request deliberately connect three lights with the Chinese three;
the scaffold disappears after that first successful request.
Read phase before every round: movement and hazards paused, unlimited reading,
clear play triangle control. It says the word when the round begins. Start action
explicitly. Steer by tapping/dragging in the arena, or arrows/WASD. Auto motion
eases towards the latest destination. Catch fireflies by contact, one per light;
avoid rain clouds that knock you gently and release one captured light. Cargo is
capped at ten; a minus control/Backspace/X releases one intentionally. Clouds have
a visible silhouette and forgiving collision circle; no damage in the first round.
Fireflies persist/respawn so every target remains reachable, without a timer.
The large send control or Space sends the cargo to the lantern. If its count
matches, animate delivery then lantern takeoff, award points and a combo, and offer
the next untimed read phase. If wrong, one of three lives is spent, the attempt's
count is crossed out, the same requested Chinese and its correct quantity are
shown in a clear correction. Leave feedback visible until acknowledged, reset
cargo for another attempt. Three wrong deliveries lose. Ten correct deliveries
win. Score is an integer; first-try precision/combo earns more, reading speed earns
nothing. Exactly one done message per finished run, no automatic continuation.
