PUBLIC CONTROLS / WALKTHROUGH
#action: title play, read-phase play, then Send fireflies to the lantern.
#arena: tap or drag to steer the mouse to the indicated position. Arrows/WASD
steer with the keyboard. It is a canvas world with no hidden solve control.
#count and #inventory: visible current cargo. #drop or X/Backspace releases one.
#listen: posts the current round's checked numeral to host speech.
#help / #help-close: suspend the run, replay the illustrated demonstration, return.
#motion: reduce motion. #restart / R: restart from every screen.
#continue / Enter: acknowledge a correction or restart a finished run.
Escape pauses/resumes. Read each request at leisure, then start flying. Catch
exactly the number of fireflies requested and deliver. The first request is three;
later requests use every number one through ten. Rain clouds release one light;
they do not take a life. Incorrect delivery takes one of three lives and displays
the attempted quantity, the requested numeral and its correct quantity. Ten correct
deliveries win. There is no reading timer or game-completion memory evidence.
